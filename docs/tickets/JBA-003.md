# JIRA TICKET: JBA-003

## Description

Permite que un candidato postule a una oferta de trabajo. Antes de crear la postulación el sistema valida tres condiciones en orden usando el cliente HTTP de JBA-001 y la base de datos.

## Dependencias
JBA-001 — Cliente HTTP del servicio de candidatos (ya implementado)
JBA-002 — CRUD de ofertas de trabajo (ya implementado)

## Flujo de validación
- ¿El candidato existe en JSONPlaceholder?   → si no: 404
- ¿La oferta existe?                         → si no: 404
- ¿La oferta tiene status = open?            → si no: 409
- ¿El candidato ya postuló a esta oferta?    → si sí: 422
- Insertar application con status = pending  → 201

## Criterios de aceptación
- POST /applications — recibe candidate_id y job_id
- Valida el candidato contra JSONPlaceholder antes de insertar
- Devuelve 404 si el candidato no existe en el servicio externo
- Devuelve 404 si la oferta no existe
- Devuelve 409 si la oferta está cerrada
- Devuelve 422 si el candidato ya postuló a esa oferta
- Devuelve 201 con la postulación creada si todas las validaciones pasan
