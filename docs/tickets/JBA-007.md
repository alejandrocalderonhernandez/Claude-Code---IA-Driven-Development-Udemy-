# JIRA TICKET: JBA-007

Implementar un manejador centralizado de errores que garantice respuestas consistentes en toda la API. El mecanismo varía por stack pero el comportamiento es el mismo en todos los casos.

## Referencia por stack

 @ControllerAdvice + @ExceptionHandler , buenas practicas de RuntimeException

## Formato estándar de error

{
  "error_code": "CANDIDATE_NOT_FOUND",
  "message": "El candidato con id 99 no existe",
  "status": 404
}

## Criterios de aceptación

- Todos los errores de la API devuelven el formato estándar definido
- Errores de negocio devuelven su código HTTP correspondiente
- Errores inesperados devuelven 500 sin exponer el stack trace
- El manejador cubre todos los features anteriores — JBA-001 al JBA-006
