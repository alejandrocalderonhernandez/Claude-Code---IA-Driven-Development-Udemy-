# JIRA TICKET: JBA-004

## Description

Permite cambiar el estado de una postulación de pending a accepted o rejected. Una vez que la postulación alcanza un estado final no puede modificarse.

## Dependencias
JBA-003 — Aplicar a una oferta (Ya implementado)

Criterios de aceptación:

- PATCH /applications/{id}/status — recibe status: accepted o rejected
- Devuelve 404 si la postulación no existe
- Devuelve 422 si el status recibido no es accepted ni rejected
- Devuelve 422 si la postulación ya tiene estado final
- Devuelve 200 con la postulación actualizada
