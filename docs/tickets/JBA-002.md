# JIRA TICKET: JBA-002

## Implementar las operaciones básicas sobre la entidad Job. Es el primer feature que escribe en nuestra base de datos.

Debe incluir la capa de persistencia, servicio y RESTfull 

Así como sus respectivas conexiones a la base de datos, las cuales se definen en el docker compose.

## Criterios de aceptación

- POST /jobs — crea una oferta con status open por defecto
- GET /jobs — lista todas las ofertas
- GET /jobs/{id} — obtiene una oferta por ID
- PATCH /jobs/{id}/close — cierra una oferta cambiando su status a closed
- Devuelve 404 si la oferta no existe
