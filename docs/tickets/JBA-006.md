# JIRA TICKET: JBA-006

## Description

Genera un reporte de una oferta con el total de postulaciones recibidas y el desglose por estado. Requiere una query con agregaciones sobre la tabla applications.

# Dependencias
- JBA-002 — CRUD de ofertas de trabajo
- JBA-003 — Aplicar a una oferta

Respuesta esperada
{
  "job_id": 1,
  "title": "Backend Developer",
  "total_applications": 5,
  "by_status": {
    "pending": 2,
    "accepted": 1,
    "rejected": 2
  }
}

## Criterios de aceptación
- GET /jobs/{id}/report — devuelve el reporte de la oferta
- Devuelve 404 si la oferta no existe
- Incluye total de postulaciones y desglose por cada estado
