# JIRA TICKET: JBA-001

** Construir el cliente HTTP que consume el servicio externo de candidatos simulado por JSONPlaceholder. Este cliente es la capa de integración que usarán todos los features que necesiten datos de candidatos. **

## Contexto técnico

GET https://jsonplaceholder.typicode.com/users
GET https://jsonplaceholder.typicode.com/users/{id}

## Criterios de aceptación

- El cliente expone el método getCandidateById(id) que consulta /users/{id}

- El cliente expone el método getAllCandidates() que consulta /users

- La respuesta se mapea a un DTO del dominio — no se expone el modelo externo directamente

- Si el servicio externo no responde, se lanza una excepción controlada
